Instance with a1.1.2_01 aabric included for [PrismLauncher](https://github.com/PrismLauncher/PrismLauncher) (should work on MultiMC aswell)

# Usage
1. Go to [releases](https://github.com/floofyplasma/aabric-prism-instance/releases)
2. Drag and drop the download link into your PrismLauncher
3. Pick the name and click OK!
